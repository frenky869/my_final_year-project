# Final Year Project - Smart Systems Collection

This repository contains two intelligent systems developed as part of a final year project:

## 🅿️ Smart Park System - Intelligent Parking Management

A comprehensive parking management solution with real-time monitoring, automated billing, and reservation capabilities.

### Features
- 🚗 **Vehicle Entry/Exit Management**: Seamless check-in and check-out process
- 📊 **Real-time Monitoring**: Track parking spot availability in real-time
- 💳 **Automated Billing**: Calculate parking fees automatically based on duration
- 📅 **Reservation System**: Allow customers to reserve parking spots in advance
- 📈 **Analytics & Reporting**: Revenue tracking, occupancy statistics, and payment analytics
- ⚙️ **Admin Panel**: Comprehensive management dashboard

### Quick Start - Smart Park System
```bash
# Install dependencies
pip install -r reqiuirements.txt

# Run the application
streamlit run smart_park.py

# Or use the quick start script
./start_smart_park.sh
```

For detailed documentation, see [SMART_PARK_README.md](SMART_PARK_README.md)
